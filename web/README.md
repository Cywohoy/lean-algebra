# 상호작용 미리보기

공개 문서는 [GitHub Pages](https://cywohoy.github.io/lean-algebra/)에서 읽을 수 있다.
단계 보기와 코드 복사는 서버 없이 동작하며, 아래의 편집·Lean 검사·자동완성은 로컬 미리보기에서 제공한다.

`interactive-preview.bat`를 실행하면 `http://127.0.0.1:8001/`에서 교재를 열 수 있다.
일반 미리보기인 `preview.bat`도 같은 기능을 제공하며 주소는 기존의 `8000`번 포트를 사용한다.
이미 문서를 생성했다면 `interactive-preview.bat -SkipBuild`로 실행할 수 있다.
Python 3와 프로젝트의 Lean 도구가 필요하며 별도의 Python 패키지는 설치하지 않는다.

코드에 포인터를 놓거나 키보드로 이동하면 오른쪽 위에 `단계`, `편집`, `복사`가 나타난다.
터치 화면에서는 이 메뉴를 항상 표시한다.

- 증명 코드를 누르면 단계 창이 열리며, 전술을 누르면 그 단계의 가정과 목표가 표시된다. `단계`로 창을 접거나 다시 열 수 있고, 이전·다음 버튼으로 이동할 수도 있다. 정리 이름의 링크는 원래대로 정의가 있는 곳으로 이동한다.
- `편집`: 편집기를 열거나 입력을 잠시 멈추면 자동으로 Lean에 전달한다. `실행` 또는 `Ctrl+Enter`로 즉시 실행할 수도 있다. 커서를 옮기면 그 위치의 가정과 목표가 표시되며, 증명의 빈 줄에서는 앞선 단계까지의 상태를 볼 수 있다.
- 정리나 지역 가정의 이름을 입력하면 Lean 서버의 자동완성 후보가 나타난다. `Ctrl+Space`로 직접 요청할 수도 있다. 위·아래 화살표로 후보를 고르면 그 타입이 표시되며, `Tab`·`Enter` 또는 후보를 눌러 입력한다. `Esc`는 목록을 닫는다. 해당 예제의 앞선 정의와 가져온 모듈에서 이름을 찾으며, 목표에 맞는 정리를 자동으로 추천하는 기능과는 구별한다.
- 몫 원소의 겹대괄호는 `\[[`, `\]]` 뒤에 `Tab`을 눌러 입력한다. `\[[]]` 뒤에 `Tab`을 누르면 `⟦⟧`를 함께 넣고 커서를 괄호 안에 둔다.
- 아직 풀지 않은 목표와 `sorry`는 `증명 중`으로 표시하고, 목표 창에서 이어서 확인한다. 실제 구문 오류나 타입 오류는 오류 목록에 남긴다.
- `초기화`: 편집 중인 코드를 교재에 실린 원래 코드로 되돌린다.
- 힌트와 풀이의 제목을 누르면 내용을 펼치거나 접을 수 있다. 현재 입문부의 연습문제 네 개에는 풀이가 있으며 기존 힌트도 접어서 표시한다.

수정한 코드는 브라우저의 로컬 저장소에 저장한다. `Exercises/`의 개인 풀이 파일과는 별도로 관리하며,
이곳에서 수정한 코드를 개인 풀이 파일로 옮기려면 `복사`를 사용한다.
코드 전체를 편집할 수 있으므로 실행 성공은 수정한 코드가 Lean의 검사를 통과했다는 뜻이다.
원래 연습문제와 같은 명제를 풀었는지까지 판정하는 채점 기능은 제공하지 않는다.

## 교재에 새 예제와 풀이 추가

기존 `savedLean` 블록에는 편집과 단계 보기 기능이 자동으로 연결된다.
각 예제의 실행 환경에는 같은 파일에서 그 예제보다 앞에 있는, 본문에 유지되는 코드만 들어간다.
`-show`로 숨긴 정의와 기호 연결도 포함하며 `-keep`인 연습문제는 포함하지 않는다.
일반 `lean` 블록은 실행 대상에 포함하지 않는다.

완성되지 않은 시도나 풀이처럼 예제 코드 파일로 내보내지 않을 코드는 다음과 같이 적는다.

````
```tryLean +error -keep
example (n : Nat) : 0 + n = n := by
  rfl
```
````

`tryLean`도 문서를 생성할 때 Lean으로 검사한다. `+error`는 오류가 발생해야 하는 예제에만 붙인다.
힌트와 풀이에는 각각 `:::hint`, `:::solution`을 사용한다.

````
:::solution
풀이의 설명을 적는다.

```tryLean -keep
example (P : Prop) : P → P := by
  intro h
  exact h
```
:::
````

인쇄용 출력에서는 조작 버튼을 제외하고 원래 코드와 힌트·풀이의 내용을 출력한다.
웹 기능을 수정한 것만으로 PDF를 다시 만들지는 않는다.

## 구성과 운영 범위

`AlgebraBook/Meta/Lean.lean`은 원래 코드에 웹용 메타데이터를 붙인다.
`AlgebraBook/Meta/Playground.lean`은 예제별 코드와 앞선 문맥을 `playground/`에 내보낸다.
웹 화면의 동작과 모양은 `assets/web/reader.js`, `reader.css`에 있다.

`serve.py`는 정적 문서와 실행 API를 제공하고 `lean_rpc.py`는 설치된 Lean 언어 서버와 통신한다.
오류와 증명 상태는 Lean 서버에서 받으며 웹에서 추측하여 만들지 않는다.
같은 브라우저 탭에서는 페이지를 이동해도 실행 세션을 재사용한다.
서버는 최대 여덟 개의 세션을 유지하며 10분 동안 사용하지 않은 세션은 다음 실행 요청 때 정리한다.

이 실행 서버는 신뢰하는 사용자를 위한 로컬 미리보기이다. `127.0.0.1`에만 연결하고 로컬 출처의 요청만 받는다.
공개 배포에서는 정적 문서와 코드 실행 서버를 분리하고, Lean 실행을 격리하는 별도의 운영 환경을 준비해야 한다.
현재 서버를 공인 주소에 연결하는 옵션은 제공하지 않는다.

브라우저에서 Lean을 직접 실행하는 WASM 방식은 본문과 분리하여
[`experiments/wasm/`](../experiments/wasm/README.md)에서 시험한다.
현재 실험에서는 기본 증명 검사와 목표 출력이 동작하지만, 교재의 Lean 4.35·Ample 환경과
커서 위치별 목표 조회는 아직 연결하지 않았다. 공개 웹 문서에는 실험용 편집기를 넣지 않는다.

검사는 다음과 같이 실행한다.

```powershell
python tests/Playground.Tests.py
```

브라우저 검사는 `tests/InteractiveReader.Tests.cjs`를 사용하며 실행할 서버 주소는 `BOOK_URL`로 지정할 수 있다.
