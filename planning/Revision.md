# 교재 재구성과 전술 개선 작업

준비 장의 선수관계를 정리하여 함수와 정수 계산을 익힌 독자가 군의 기본 계산으로 진행할 수 있게 한다. 유한군의 위수 앞에서 동치관계와 유한집합 이론으로 돌아오는 경로를 제공한다. 정의와 완성된 증명은 보존하며 개인 풀이 파일은 수정하지 않는다.

## 본문 재구성

- [x] 준비 장을 문법, 증명, 집합, 함수, 자연수와 정수, 동치관계와 몫집합, 집합의 크기와 유한성, 무한집합의 크기로 구성한다.
- [x] 순서쌍의 비교를 함수의 곱 사상 앞에 두고 `Fin`의 값·범위·구성을 부분타입 뒤에서 소개한다. 번호 변경과 삭제는 유한집합의 증명에 남긴다.
- [x] 역함수의 정의와 성질을 함수 절에 유지하고 존재명제와 값의 차이에 관한 긴 논의를 하위 절로 묶는다.
- [x] 기수의 일반적인 대소 관계를 무한집합 절로 옮긴다. 기수 정의, 원소 수의 유일성, 자연수 형변환의 순서는 유지한다.
- [x] 두 원소 군의 구성을 군의 정의 뒤에 두고 거듭제곱과 원소 수 계산을 각 관련 절로 옮긴다.
- [x] 군의 위수를 기본 계산·예제·군 자동화 뒤의 2.8로 옮긴다.
- [x] 연습문제를 각 절에 배치하고 집합의 곱의 원소 수 문제에 필요한 번호 대응을 설명한 예제로 제공한다.
- [x] 기본 읽기와 군론을 먼저 읽는 경로를 본문에 명시하고 선수관계를 확인한다.
- [x] 연습문제 원본, 목차, 기호 부록, 계획·사용 안내와 이전 URL 연결을 갱신한다.

## 전술의 설명과 구현

- [x] 부록에서 기본 용법과 확장 용법을 구분하고 표준 Lean과 다른 교재 관례를 안내한다.
- [x] 대표적인 실패와 수정 예제를 제공한다. 오류 메시지는 영어로 쓰고 수학적 조건과 지원 범위를 구별한다.
- [x] 목표 결합, 분해 패턴, 모호한 결과 타입의 오류에 필요한 정보와 해결 방법을 추가한다.
- [x] `arith`, `card`, `group_calc`의 범위와 실패의 의미를 같은 기준으로 설명한다.
- [x] 기존 명령의 선택적 추적을 통해 성공한 자동화의 정리·조건을 확인하게 한다. 실패한 탐색 경로를 결과처럼 표시하지 않는다.
- [x] 새 실패·추적 동작과 결과 상태의 회귀 검사를 추가하고 기존 검사와 편집기 표시 검사를 실행한다.
- [x] Lean 버전 변경 시 실행할 검증 절차와 가져온 `wlog`의 관리 기준을 기록한다.

## 이후 단원에서 진행할 확장

환 계산은 환 법칙을 직접 증명한 뒤 도입한다. 준동형 계산은 실제 보존 법칙의 반복을 확인하여 기존 자동화와 연결한다. 새로운 구조의 `ext`·`indisc`와 `card` 규칙은 해당 비교 원리와 크기 정리를 증명한 뒤 등록한다. 다음 전술 제안 기능은 실제 실패 사례가 모인 뒤 검토한다.

## 완료 확인

- [x] 본문의 완성된 증명에 `sorry`나 추가 공리가 없고 미완성 문제는 `savedLean -keep`으로 분리되어 있다.
- [x] 개인 풀이 파일의 내용이 보존되어 있다.
- [x] 문서 생성, 추출 Lean 코드, 연습문제 원본 및 관련 전술 검사가 통과한다.
- [x] 두 독서 경로와 링크를 확인하고 작업 결과를 보고한다. PDF는 생성하지 않는다.

## 검증 결과

- 웹 문서 생성과 16개 절의 번호·이전 주소 연결을 확인했다.
- 추출 코드 18개, 연습문제 원본 12개, 검사 코드 33개로 이루어진 Lean 파일 63개가 모두 통과했다.
- 선택적 추적의 정리·조건 출력과 실제 Lean 서버의 새 문서·증분 편집 상태 표시 검사가 통과했다.
- 연습문제 초기화·백업 검사가 통과했으며 기존 개인 풀이 파일의 내용이 보존되었다.
- 새 실패 사례와 추적 안내는 영어 URL로 제공한다. 문서에서 옮긴 모듈의 이전 추출 파일은 자동으로 정리한다.
- 기존 가져오기 경로는 유지하면서 실제 본문 모듈의 선수관계를 분리했다.

환 계산, 준동형 계산과 이후 구조의 비교 규칙은 해당 내용을 집필하고 기본 성질을 증명한 뒤 확장한다.

## 재구성 후 검토

- 2.3~2.6 연습문제 원본이 기존 집계 모듈을 통해 기수 이론과 군 자동화까지 가져오고 있었다. 가져오기 경로를 `Groups.Permutations`로 좁히고, 연습문제 풀이 검사에서도 기수·동치관계·군 자동화가 포함되지 않는지 확인한다. 개인 풀이 파일의 기존 경로는 유지한다.
- 정수 거듭제곱 증명에 별도 설명 없이 사용한 `show … by …` 세 곳을 앞에서 배운 `have`와 `rw`로 바꾸었다.
- 번호 쌍의 전단사 예제에 범위 부등식, 몫·나머지의 복원, 범위가 0인 경우의 설명과 증명 주석을 보충했다.
- 군 자동화 예제의 설명에서 실제 계산에 필요하지 않은 역원의 역원 법칙을 언급한 문장을 고쳤다. 무한집합 절의 자동화 설명에는 앞의 유한성 절로 가는 참조를 명시했다.
- 기본 방법으로 풀리는 무한성 전달 문제의 반복적인 힌트를 덜어 냈다.
- 이전 준비 장과 군의 위수 주소를 현재 본문에 직접 연결했다. 새 출력 폴더에서도 이전 주소와 도착 페이지의 위치 표시를 검사하여 기존 출력 파일에 기대지 않도록 했다.
- 본문과 수정한 여덟 연습문제 원본 묶음의 선언 목록이 일치함을 확인했다.
